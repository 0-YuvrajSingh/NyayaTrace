# RQ3 evaluator protocol (fixed; to be used verbatim when raters are enrolled)

You are evaluating presentation transparency, NOT legal correctness.

## What you receive

For each case, two displays (Display 1 / Display 2, order randomized) of
the SAME retrieved evidence set. Both displays are simply two presentational
formats. Treat neither as privileged and do not try to infer any intended
ranking between them. Work only from what is visible.

## Rules

1. Evaluate only the supplied artifacts; rely only on visible evidence.
2. Do not infer hidden model reasoning; there is none to judge.
3. Do not evaluate any hidden chain-of-thought.
4. A citation's presence never implies the conclusion is correct.
5. Longer is not better; rate organization and locatability only.
6. Assess whether you CAN verify the basis — never whether you AGREE with it.

## Rubric (1–5 each display; 1=strongly disagree … 5=strongly agree)

1. Evidence linkage — "I can identify which evidence supports the stated output."
2. Citation verifiability — "I can locate and verify the cited authority/passage."
3. Traceability — "I can follow Issue → Authority/Rule → Evidence → Conclusion."
4. Explanation clarity — "The explanation is organized and understandable."
5. Transparency/inspectability — "The presentation makes the basis of the output easier to inspect."

Then: forced preference (Display 1 / Display 2 / tie) + one-paragraph
rationale + any confusion encountered. Retrieval misses are in scope:
if a display shows little or no evidence, rate what is there (low linkage
scores with a note are informative, not errors).
